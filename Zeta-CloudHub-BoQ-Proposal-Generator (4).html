Step 1

Price Book — base costs & default margins

When pricing changes, update it here — no need to rebuild the application. Download the current price book, edit the cost column in Excel, then upload the same sheet back. Required column headings: SKU, Category, Unit, Base Cost (USD / month), Default Margin %. Only SKU and a cost column are mandatory — headings are matched loosely, so “Item”, “Service”, “Base Price” or “GM %” also work. The uploaded book is saved in this browser and is used by the BoQ, the proposal and the deck.
